1. Which AI tools or models did you use?

In this project, I primarily used three AI tools. ChatGPT was used for designing the system architecture, UML structure, and document planning. Claude Code was used to generate model classes, service classes, and CSV persistence code. Gemini was used to review the generated code, identify design issues, and suggest improvements before merging changes.


2. Which prompt was the most useful?
The most useful prompt was the initial structural query I gave to ChatGPT:

“请你以项目架构师的身份，开发一个关于王者荣耀的Java 信息管理系统，设计中应包含继承、接口、集合和类。至少包含 7 个类：Person、Player、Admin、Hero、Equipment、Team、MatchRecord，不能全部放在Main类里面，功能包含Player Lookup、Team Overview、Hero Details、Equipment Statistics、Match History、Leaderboard，管理员权限，登录系统，不要直接给我完整的代码，而是分层设计” This prompt was a lifesaver because it stopped the AI from dumping a massive, single-file monolithic block of code that would be impossible to debug. By forcing it to focus purely on class boundaries and layered responsibilities first, it gave me a clean Model-Service-Presentation architecture that made integrating the later code much easier.


3. Which AI-generated suggestion was wrong?

The implementation generated by Claude code allows an unlimited number of players to be added to a team. While the code technically works correctly, it ignores the game rules' requirement to limit the number of team members; this issue was discovered during testing.


4. How did you verify AI code?

I validated the AI-generated code through human code review and local functional testing. Each generated class underwent manual testing for key functionalities such as compilation in IDEA, CRUD operations, team management, ranking, and CSV persistence. I also conducted independent code reviews using Gemini.


5. What bugs did you fix yourself?

One of the most important bugs I fixed was the team capacity issue. Initially, the system allowed an unlimited number of players to join a team. I added a MAX_MEMBERS limit to the Team.java file and introduced an exception handling mechanism to prevent invalid registrations. I also updated the user interface logic to catch the exception and display a friendly error message instead of terminating the application.


6. What Java concept did you learn?

This project deepened my understanding of object-oriented programming concepts, particularly encapsulation, inheritance, abstraction, and polymorphism. I also gained practical experience using Java collections, exception handling, file I/O, and layered architecture design.


7. What are you still unsure about?

I am still unsure about designing larger-scale software systems and making architectural decisions independently. Throughout this project, I relied on AI suggestions when designing layered architecture and service responsibilities. While I understand the final structure, I would like to gain more experience making these design decisions without external assistance.


8. Did AI make the project easier or harder?

AI streamlines project processes by accelerating implementation and providing architectural suggestions. However, because the generated solutions may not fully meet business needs, careful validation is still required. Human review remains crucial throughout the development process. But AI has indeed saved us a significant amount of time.


9. Which parts were mainly written by you?

I was responsible for project planning, task decomposition, Git history management, documentation writing, testing, prompt engineering, AI coordination, and final verification. I also reviewed all AI-generated code before integration and personally identified and fixed the team-capacity bug discovered during testing.


10. Which parts were mainly generated by AI?

AI is primarily used to generate model classes, service layer boilerplate code, CSV persistence implementations, UML sketches, and document drafts. Although AI generated a significant portion of the implementation, all generated code was reviewed, tested, and integrated manually before being accepted into the final project.
